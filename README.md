# PrayerGem Pro v2.0.4

PrayerGem Pro is a lightweight Windows prayer-times application with Arabic and English support, offline prayer-time caching, Qibla direction, Islamic/Gregorian calendar, Adhan alerts, Mini Mode, monthly prayer timetable, backup/restore, and built-in update checking.

## Main Features

- Accurate prayer times with multiple calculation methods
- Offline prayer-time cache
- Qibla direction
- Arabic and English interface
- Adhan and pre-Adhan notifications
- Silent/Mute modes
- Mini Mode
- Islamic and Gregorian calendar
- Monthly prayer timetable
- Popular cities and custom city search
- Backup and restore
- Built-in update checking
